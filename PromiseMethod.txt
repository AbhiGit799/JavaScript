Here’s a beginner-friendly breakdown of all the major JavaScript Promise methods: 
they help you create, resolve, reject, and combine asynchronous tasks. 
The most important ones are resolve(), reject(), then(), catch(), finally(), and 
static helpers like Promise.all(), Promise.race(), Promise.any(), and Promise.allSettled(). 

🔑 Core Concepts
=================
A Promise represents a value that will be available in the future.
It can be in one of three states: Pending, Fulfilled, or Rejected.
You use methods to control or react to these states.

📦 Constructor
===============
new Promise(executor) → Creates a new promise.
The executor function receives two arguments: resolve (success) and reject (failure).

const promise = new Promise((resolve,reject)=>{
   const success = true; 
   if(success)
   {
     resolve("Done");
   }
   else{
    reject("Failed");
   }
});

🛠 Instance Methods
=====================
then() → Runs when the promise is fulfilled.
        promise.then(value => console.log(value));

catch() → Runs when the promise is rejected.
       promise.catch(error => console.error(error));

finally() → Runs after the promise settles (fulfilled or rejected).
       promise.finally(() => console.log("Always runs"));


🛠 Static Methods
==================
Promise.resolve(value) → Creates a promise that is immediately fulfilled.
 Promise.resolve(42).then(x => console.log(x)); // 42

Promise.reject(error) → Creates a promise that is immediately rejected.
  Promise.reject("Oops").catch(err => console.error(err));


Promise.all(promises) → Waits for all promises to fulfill, returns results as an array. Rejects if any fail.

Promise.allSettled(promises) → Waits for all promises to settle (fulfilled or rejected), returns their status.

Promise.race(promises) → Returns the result of the first promise to settle.

Promise.any(promises) → Returns the result of the first fulfilled promise. Rejects only if all fail.




## 📊 Quick Comparison Table

| Method            | **Purpose**                    | **Example Result** |
|-------------------|--------------------------------|--------------------|
| resolve           | Create fulfilled promise       | `42` 
| reject            | Create rejected promise        | `"Error"` 
| then              | Handle success                 | `"Done!"` 
| catch             | Handle error                   | `"Failed!"` 
| finally           | Always run cleanup             | `"Always runs"` 
| all               | Wait for all                   | `[val1, val2]` 
| allSettled        | Wait for all outcomes          | `[{status:"fulfilled"}, {status:"rejected"}]` 
| race              | First settled wins             | `val1` 
| any               | First success wins             | `val2`

Use all when both results are required.
Use race when you only care about the fastest response.
Use any when you just need one success.
Use allSettled when you want all outcomes, even failures.

🌐 Promise Methods in Action

1. Promise.resolve
Creates a promise that is already fulfilled.
Promise.resolve(10).then(val => console.log(val)); // 10

2. Promise.reject
Creates a promise that is already rejected.
Promise.reject("Error!").catch(err => console.error(err)); // Error!


3. Promise.all
Waits for all promises to succeed. If one fails, the whole thing fails.
Promise.all([Promise.resolve(1), Promise.resolve(2)])
  .then(vals => console.log(vals)); // [1, 2]

4. Promise.allSettled
Waits for all promises, whether they succeed or fail.
Promise.allSettled([Promise.resolve(1), Promise.reject("Oops")])
  .then(results => console.log(results));
// [{status:"fulfilled", value:1}, {status:"rejected", reason:"Oops"}]


5. Promise.race
Returns the result of the first promise to settle (success or failure).
Promise.race([
  new Promise(res => setTimeout(() => res("Fast"), 100)),
  new Promise(res => setTimeout(() => res("Slow"), 500))
]).then(val => console.log(val)); // "Fast"


6. Promise.any
Returns the first successful promise. Ignores failures unless all fail.
Promise.any([Promise.reject("Fail"), Promise.resolve("Win")])
  .then(val => console.log(val)); // "Win"


const api1 = fetch("https://api.example.com/user");
const api2 = fetch("https://api.example.com/orders");

// Wait for both
Promise.all([api1, api2])
  .then(([userRes, orderRes]) => {
    console.log("User and Orders ready!");
  })
  .catch(err => console.error("One failed:", err));
